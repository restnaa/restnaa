# Restnaa notification troubleshooting

Confirm you launched the installed Restnaa candidate, not a frontend browser preview. Its Windows app ID is com.restnaa.desktop and binary restnaa.exe. Check Settings for enabled notifications, permission and attention diagnostics. Send test reminder tests OS dispatch only; it does not fabricate a scheduled break.

Check app Pause, working hours, category enablement and Quiet mode. Windows can suppress banners even when a notification is retained in notification history. Use the tray to open the current break. There are no Windows toast action buttons. Automatic break windows have their own persisted toggle and require notification eligibility.

DND detection is best effort. Do not bypass Windows policy. A submitted result or history entry is not proof of visible delivery. Report version, Windows version, diagnostic text and reproduction steps without private databases. Installed dispatch/banner/click/denial acceptance for the new identity remains pending.

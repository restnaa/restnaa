# Restnaa desktop UI plan

Use Dashboard, Settings and History navigation in the accessible dark desktop shell. First-run configuration is in Settings; no standalone Welcome route. Render only typed Rust state and real history. Keep local landscape/icon assets, responsive cards, semantic controls, visible focus, keyboard access, contrast and reduced-motion support.

Preserve Rust native/storage/scheduler contracts and no-JS-reminder-timer rule. Validate desktop, minimum width, compact, high DPI, zoom and forced colors with browser tests; native identity/visibility/focus and notification behavior require installed tests. Current results are in IDENTITY_RESET.md.
